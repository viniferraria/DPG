# What this is

DPG (Decision Predicate Graph) is a Python library, version `0.1.6`, that explains tree ensembles by
turning them into a single interpretable graph. Nodes are decision predicates (`petal length <= 2.45`)
and class/prediction outcomes; edges are directly-follows relations mined from replayed decision paths.

It is built on scikit-learn ensembles, NetworkX/igraph for graph analysis, and Graphviz + matplotlib for
rendering.

# Package layout

Two top-level packages, with a strict one-way dependency:

```
dpg/       core library      ──imports──▶  metrics/    graph metrics
```

`metrics/` is imported by `dpg/`, never the reverse.
